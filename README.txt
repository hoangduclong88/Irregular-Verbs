IRREGULAR VERBS PORTABLE GAME - CLEAN TWO-FORM ANSWERS

This version randomizes when the software is opened.

Randomized immediately after opening:
- The order of all 50 questions
- The positions of all 4 answers A/B/C/D in every question

Answer format:
- Every answer has only this format: past form / past participle
- No answer contains long alternatives like proven/proved / proven/proved
- Example: proved / proven

How to use:
1. Unzip the folder.
2. Double-click Start_Irregular_Verbs_Game.bat, or open Irregular_Verbs_Game.html.
3. Click Start Game.
4. Students choose A/B/C/D.
5. The correct answer is highlighted after clicking.
6. Click Next to continue.

Offline. No internet needed.
